# Python Pomodoro Timer

A lightweight desktop productivity timer built with Python and the Tkinter GUI library. 

## Features
* Standard 25-minute Pomodoro work sessions.
* Start, Pause, and Reset functionality.
* Real-time countdown display using `root.after()` event scheduling.

## How to Run
Ensure you have Python installed, then run the application from your terminal:
```bash
python pomodoro.py
